Takes no arguments. Each invocation rescans everything and redeploys the same dashboard
URL. All state lives in the DevOS repo (`C:\Users\Jonathan\Projects\personal-dev-os`).

## 1. Scan

Run:

```
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\Jonathan\Projects\personal-dev-os\scripts\mission-control-scan.ps1"
```

(Absolute path — `sync.ps1` installs only this skill directory to `~/.claude/skills/`;
the script stays in the source repo.)

Capture stdout and parse it as JSON. If the exit code is nonzero, the output does not
parse, or `schemaVersion` is not `1`: stop, report the failure verbatim, and do not
render anything — never build the dashboard from partial or guessed data.

## 2. Load state

Read `C:\Users\Jonathan\Projects\personal-dev-os\.claude\mission-control.json` if it
exists: `{ artifactUrl, htmlPath, lastPublished, lastScanGeneratedAt }`. An absent file
means first run.

## 3. Calibrate design

Invoke the `artifact-design` skill before writing any HTML — this is a personal status
page, expect a light design pass. Do not pull in `dataviz`; badges and a table cover
everything here.

## 4. Render

Overwrite `C:\Users\Jonathan\Projects\personal-dev-os\.claude\mission-control.html`
(the same path every run). The page is a pure projection of the scan JSON — render its
values verbatim, never invent, embellish, or add projects the scan didn't report.

Sections, in order:

1. **Header** — "Mission Control", the scan's `generatedAt`, and a summary strip:
   `N projects · N need attention · N inbox candidates · index drift: N`.
2. **Needs attention** — a ranked list (by `attentionScore`, descending): flag badge +
   project + the concrete fact (e.g. "Opal — 37 dirty files, last commit 510 days
   ago"). If nothing scores, render a single "All clear" line — the section must earn
   its space.
3. **Projects table** — one row per project, sorted `attentionScore` desc then last
   commit desc. Columns: Project (nested repo path small underneath), Branch (badges
   for detached / no commits), Dirty, Last commit (relative + subject truncated ~60
   chars, full text in a title attribute), ±upstream (`—` when none), STATUS.md
   (ok / stale / missing badge, `Updated:` value when present), Tasks (count, filenames
   in a title attribute), Verify (✓/—).
4. **Brain** — inbox candidate filenames, latest weekly review or "none yet", and the
   index-drift detail (missing-from-index / in-index-not-on-disk) with a one-line nudge
   toward `/devos-repo-brief` or `/devos-promote`.
5. **Footer** — threshold legend (active <14d · cooling 14–30d · dormant >30d · stale =
   STATUS.md `Updated:` older than last commit) and a provenance line: generated by
   `/devos-mission-control` via `scripts/mission-control-scan.ps1`, data as of
   `generatedAt`.

Theme-aware (`prefers-color-scheme` plus a `data-theme` override), fully self-contained
(no external requests), responsive — the table scrolls horizontally inside its own
container, the page body never does. No JavaScript beyond, at most, a tiny theme toggle.

## 5. Publish

Call the `Artifact` tool on that file path with favicon 🛰️ (keep it 🛰️ on every
redeploy). If state held an `artifactUrl`, pass it as the `url` parameter so the
existing bookmark keeps working across sessions. If publishing with the stored URL
fails, publish fresh and state plainly in chat that the URL changed.

## 6. Save state

Rewrite `.claude/mission-control.json` (UTF-8) with the current `artifactUrl`,
`htmlPath`, `lastPublished`, and the scan's `generatedAt`.

## 7. Summarize

One paragraph in chat: the top 2–3 attention items with their concrete numbers, then
the dashboard link. No tables, no transcript dumps — the dashboard is the detail view.

## Guardrails

Read-only outside this repo — the scan never modifies other repos, and neither does
this skill. It writes only the two gitignored `.claude/mission-control.*` files. It
never commits or pushes. It never reads or displays `.env`/credential content. If the
scan reports something surprising (drift, a missing repo), report it on the dashboard —
do not "fix" other repos or `brain/projects.md` from this skill.
